Windows keyboard shortcuts

The shortcuts that work across Windows 11 and Windows 10, grouped by what you are doing. They follow Microsoft's own published list, read on 12 November 2026, reworded and trimmed to the ones most people can use. Where Windows 10 behaves differently, the line says so.

The ten to learn first

If you learn nothing else on this page, learn these. Together they remove most of the reaching for the mouse in an ordinary day.

  1. Win + D shows the desktop, and brings your windows back when pressed again.
  2. Alt + Tab switches between open windows.
  3. Win + E opens File Explorer.
  4. Win + L locks the computer when you leave your desk.
  5. Win + V opens the clipboard history, so that you can paste something you copied earlier. Windows asks you to switch the history on the first time.
  6. Win + Shift + S captures part of the screen.
  7. Win + Left arrow and Win + Right arrow put two windows side by side.
  8. Win + . (period) opens the emoji panel.
  9. Ctrl + Shift + Esc opens Task Manager when a program stops responding.
  10. F2 renames the selected file.

"Win" is the key with the Windows logo, between Ctrl and Alt.

Things worth knowing

Deleting with Shift + Delete has no undo. The file does not go to the Recycle Bin. Use plain Delete unless you are certain.

Clipboard history must be switched on once. Press Win + V and accept the offer. From then on, the last several things you copied are kept until the computer restarts, and you can pin the ones you use often.

Snap is the quickest way to compare two documents. Press Win + Left arrow on one window, then choose the second from the pictures Windows offers for the other half.

A second desktop keeps work apart. Win + Ctrl + D makes one. Put your email on one desktop and the report you are writing on another, and move between them with Win + Ctrl and an arrow.

Some keys depend on the keyboard. Compact laptops put Home, End, PrtScn and the F keys behind the Fn key. If a shortcut does nothing, try it with Fn held down. A Copilot key on newer keyboards opens Microsoft's assistant or, where that is not available, Windows search.

Programs can take over a shortcut. Windows provides the defaults listed here, but an individual program is free to use a combination for something else.
