Excel keyboard shortcuts

Excel has hundreds of shortcuts. This page lists the ones that pay for the effort of learning them, grouped by task. The first column is for Excel on Windows and the second for Excel on the Mac. Where the Mac column is empty, the Windows keys usually work with Cmd in place of Ctrl, or there is no single equivalent.

The twelve to learn first

  1. Ctrl + Arrow key jumps to the edge of the data. It is the fastest way around a big sheet.
  2. Ctrl + Shift + Arrow key selects to the edge of the data.
  3. Ctrl + Space selects the column, and Shift + Space the row.
  4. F2 edits the cell without the mouse.
  5. F4 adds dollar signs to a reference while editing, and repeats the last action otherwise.
  6. Alt + = inserts a SUM for the cells above or beside.
  7. Ctrl + D fills down from the cell above.
  8. Ctrl + ; enters today's date.
  9. Ctrl + 1 opens Format Cells.
  10. Ctrl + Shift + L switches filter buttons on and off.
  11. Ctrl + T turns the data into a table.
  12. Ctrl + Z undoes. Use it freely.

The Alt key opens the whole ribbon

On Windows, press and release Alt and small letters appear over the ribbon tabs. Press a letter to open a tab, then the letter over the command you want. So every command in Excel has a keyboard route, even without a shortcut of its own. Some worth remembering:

  • Alt, H, O, I fits the column width to its contents.
  • Alt, H, V, V pastes values only.
  • Alt, W, F, F freezes panes at the active cell.
  • Alt, A, C clears a filter.
  • Alt, N, V inserts a PivotTable.

These are typed one key after another, not held together.

Selecting a whole table quickly

Click any cell of the data and press Ctrl + A. Excel selects the block bounded by empty rows and columns. From a corner, Ctrl + Shift + Right arrow then Ctrl + Shift + Down arrow does the same and lets you stop part of the way.

A blank row or column inside the data stops these jumps, which is one good reason to keep data free of gaps.

Laptops and the F keys

On many laptops the top row controls brightness and volume, and F2, F4 and the rest need Fn held as well. Most laptops have an Fn Lock, often Fn + Esc, that swaps this round. For anyone who uses Excel daily, it is worth switching.
