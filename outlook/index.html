Outlook keyboard shortcuts

These shortcuts are for the classic Outlook program on Windows, the one that comes with Microsoft 365 and Office. The new Outlook for Windows and Outlook on the web share many of them, and under their settings you can choose which program's shortcut style to follow.

The ten to learn first

  1. Ctrl + N starts a new message when you are in Mail.
  2. Ctrl + R replies, and Ctrl + Shift + R replies to all.
  3. Ctrl + F forwards a message. In Outlook it does not mean find.
  4. Ctrl + Enter sends the message you are writing.
  5. Ctrl + E or F3 jumps to the search box.
  6. Ctrl + 1 shows Mail and Ctrl + 2 shows the Calendar.
  7. Delete removes the selected message.
  8. Ctrl + Shift + V moves a message to a folder.
  9. Insert flags a message for follow-up.
  10. Ctrl + Q marks as read and Ctrl + U as unread.

Ctrl + F forwards

In nearly every other program, Ctrl + F means find. In classic Outlook it forwards the selected message. People send a half-finished forward by accident for exactly this reason. To search, use Ctrl + E or F3. To find text inside an open message, press F4.

Work through an inbox from the keyboard

With the message list selected, the arrow keys move from message to message and the reading pane shows each one. A simple routine:

  • Space to read down the message;
  • Ctrl + R to reply, or Delete to remove, or Backspace to archive;
  • Ctrl + Shift + V and the first letters of a folder name to file it;
  • the down arrow for the next.

With a little practice, an inbox clears much faster this way than with the mouse.

"New from anywhere"

The shortcuts with Ctrl + Shift and a letter create an item of a given kind whatever part of Outlook you are in: M for a message, A for an appointment, Q for a meeting, C for a contact, K for a task. You do not have to switch to the Calendar to note an appointment that someone mentions in an email.

Sending by accident

Ctrl + Enter sends at once. The first time you press it, Outlook asks whether you want to use that shortcut for sending. If you find that you send messages too early, it can be switched off under File, Options, Mail, in the Send messages section.

The new Outlook and Outlook on the web

The newer Outlook for Windows and the web version let you pick a shortcut style under Settings, General, Accessibility. One of the choices follows classic Outlook, and another follows Gmail. Pressing the question mark key in those versions shows the list for the style in use.
