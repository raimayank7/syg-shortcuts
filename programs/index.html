How the pages are arranged

Systems. The Windows and Mac pages cover the shortcuts that belong to the operating system itself: windows, the desktop, files, screenshots and text editing. These work whatever program is open.

Browsers. One page covers Chrome, Edge and Firefox together, since they share almost all their keys, and says where they differ.

Office programs. Excel, Word, PowerPoint and Outlook each have their own page. PowerPoint's separates the keys for building slides from the keys for presenting.

Google's apps. Google Docs, Google Sheets and Gmail. Gmail's shortcuts are single letters and must be switched on first; its page shows how.

Other tools. VS Code for people learning to code, YouTube for controlling videos, and the terminal for the command line on Linux and the Mac.

Reading a table

Each row has the keys and what they do. Where a program runs on both Windows and Mac, there are two key columns: Windows first, Mac second. A blank Mac cell means either that the same keys work with Cmd in place of Ctrl, or that there is no single equivalent.

Alternatives are joined by "or": either set of keys does the job.

Filtering and printing

The box at the top of each page hides the rows that do not match what you type. Type "paste" to see every paste shortcut on the page, or "Alt" to see everything that uses the Alt key.

The Print button produces a two-column sheet of the tables alone. Printed at normal size, most pages fit on two or three sides.

A program you use is not here

The quickest way to find any program's shortcuts is inside the program itself: look at its menus, where shortcuts are printed beside the commands, or search its Help for "keyboard shortcuts". The guide on how to learn shortcuts lists more ways. To suggest a program for this site, use the contact page.
