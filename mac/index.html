Mac keyboard shortcuts

The shortcuts that every Mac user leans on, grouped by task. If you have come from Windows, start with the section on the modifier keys, because the main key is different.

The Mac's modifier keys

KeySymbol on menusRoughly equal to, on Windows
Command (Cmd)⌘Ctrl, for most shortcuts
Option⌥Alt
Control (Ctrl)⌃used far less than on Windows
Shift⇧Shift
Fn or the globe keyFn

The rule of thumb for switchers: where Windows uses Ctrl, the Mac uses Command. Copy is Cmd + C, paste is Cmd + V, save is Cmd + S. Menus on a Mac show each command's shortcut beside it, using the symbols above, so the menus are also the best cheat sheet.

The ten to learn first

  1. Cmd + Space opens Spotlight, the search that also starts apps and does sums.
  2. Cmd + Tab switches between open apps.
  3. Cmd + Q quits the app. Closing a window with Cmd + W usually leaves the app running.
  4. Cmd + C, Cmd + V, Cmd + X, Cmd + Z copy, paste, cut and undo.
  5. Cmd + Shift + 4 captures part of the screen.
  6. Cmd + Option + Esc opens Force Quit for an app that has frozen.
  7. Cmd + , (comma) opens the settings of whichever app is in front.
  8. Space on a selected file in Finder shows a quick preview.
  9. Cmd + Delete moves the selected file to the Bin.
  10. Ctrl + Cmd + Q locks the screen.

Things that surprise people coming from Windows

Cut and paste for files works differently. Finder has no Cmd + X for files. Copy the file with Cmd + C, go to the new place, and press Cmd + Option + V. That moves it.

Return renames, it does not open. To open the selected file from the keyboard, press Cmd + O or Cmd + Down arrow.

The Delete key deletes backwards. It does what Backspace does on a Windows keyboard. Hold Fn with it to delete forwards.

Closing the last window does not quit most apps. The app stays in the Dock with a dot under it. Cmd + Q quits it properly.

Home and End are missing from laptop keyboards. Cmd with the left and right arrows does their job. Fn with the left and right arrows scrolls to the top and bottom of a page.

Screenshots are saved to the Desktop by default. The panel opened by Cmd + Shift + 5 has an Options menu to choose another place.

Finding any shortcut

Open the Help menu of any app and type the name of a command. The Mac shows where the command lives in the menus, and its shortcut. Custom shortcuts for menu commands can be added in System Settings, under Keyboard, Keyboard Shortcuts.
