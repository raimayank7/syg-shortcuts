VS Code keyboard shortcuts

Visual Studio Code is the free code editor that most beginners now start with. It can be driven almost entirely from the keyboard. The first column is for Windows and Linux, the second for the Mac.

The two that unlock everything

Ctrl + Shift + P opens the Command Palette. Type a few letters of what you want, such as "format" or "terminal" or "theme", and every matching command appears, with its own shortcut shown beside it. You never need to remember where something is in the menus.

Ctrl + P opens Quick Open. Type part of a file name and press Enter to open it. In a project of hundreds of files, it is far quicker than the file tree.

The next eight

  1. Ctrl + / turns the current line into a comment, and back.
  2. Alt + Up arrow and Alt + Down arrow move the line up or down.
  3. Shift + Alt + Down arrow copies the line below itself.
  4. Ctrl + D selects the next occurrence of the selected word, for editing several at once.
  5. Ctrl + ` opens the built-in terminal.
  6. Ctrl + B shows or hides the side bar.
  7. Shift + Alt + F formats the whole file.
  8. F2 renames a variable or function everywhere it is used.

Editing several places at once

Multiple cursors are the feature that most changes how fast you edit. Put the cursor on a word and press Ctrl + D. The word is selected. Press Ctrl + D again and the next occurrence is selected too. Type, and both change together. It is a quick, visible way to rename something in a small area, and safer than find and replace because you see each one being added.

Line shortcuts need no selection

Ctrl + X, Ctrl + C and the Alt + arrow keys act on the whole line when nothing is selected. To move three lines, select any part of all three and press Alt + Up arrow.

Shortcuts can be changed, and extensions add more

Ctrl + K followed by Ctrl + S opens a searchable list of every shortcut, where any of them can be changed. Extensions add their own. If a shortcut here does something else on your computer, look it up in that list. People who come from another editor can install a keymap extension that brings its shortcuts along.

In VS Code, Help, Keyboard Shortcuts Reference opens the official one-page sheet for your operating system.
