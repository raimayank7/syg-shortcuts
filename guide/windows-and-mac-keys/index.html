Windows and Mac keyboards: which key is which

People who move between a Windows computer and a Mac, or who plug one kind of keyboard into the other kind of computer, are tripped up by the same few keys. This guide matches them up.

The modifier keys

Windows keyboardMac keyboardNotes

AltOption (⌥)Used for alternatives, and for typing special characters on a Mac

ShiftShift (⇧)The same

The one-line summary: on a Mac, think Command where you would press Ctrl.

The order of the keys

Beside the space bar, a Windows keyboard has Ctrl, Windows, Alt. A Mac keyboard has Control, Option, Command. So the key your thumb finds for copy and paste is in a different place: next to the space bar on a Mac, at the corner on Windows. This is what feels strange for the first week, more than any difference in the shortcuts themselves.

Things that work differently, not just with different keys

Quitting. On Windows, closing the last window of a program ends it. On a Mac, most programs keep running with no windows open, until you press Cmd + Q.

Switching. Alt + Tab on Windows steps through windows. Cmd + Tab on a Mac steps through programs. To move between two windows of the same program on a Mac, press Cmd and the grave accent key, above Tab.

Moving files. Windows uses cut and paste, Ctrl + X then Ctrl + V. In the Mac's Finder you copy with Cmd + C and then press Cmd + Option + V at the destination to move.

Renaming. F2 on Windows. On a Mac, Return renames and Cmd + O opens.

Maximising. The Windows maximise button fills the screen and keeps the taskbar. The Mac's green button goes to a separate full-screen space. Hold Option while clicking it for a plain enlarge.

Using the other kind of keyboard

A Windows keyboard on a Mac. It works. The Windows key acts as Command and Alt acts as Option, which puts them the opposite way round from a Mac keyboard. System Settings, Keyboard, Keyboard Shortcuts, Modifier Keys lets you swap them so that your fingers find Command next to the space bar.

A Mac keyboard on Windows. Command acts as the Windows key and Option as Alt. Keys that the Mac keyboard lacks, such as PrtScn, have on-screen or shortcut alternatives, for example Win + Shift + S for a screen capture.

Chromebooks

A Chromebook keyboard follows the Windows pattern, with Ctrl and Alt. In place of Caps Lock it has a launcher or search key, which works rather like the Windows key. The top row has browser keys in place of F1 to F12. A Chromebook has its own searchable list of shortcuts, in the Key Shortcuts app.

Symbols for the keys

Mac menus show shortcuts with symbols, which puzzles newcomers: ⌘ is Command, ⌥ is Option, ⌃ is Control, ⇧ is Shift, ⌫ is Delete and ⎋ is Esc. Windows menus spell the names out.
