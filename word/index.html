Word keyboard shortcuts

The shortcuts that matter for writing and formatting in Microsoft Word. The first column is for Word on Windows and the second for Word on the Mac.

The ten to learn first

  1. Ctrl + S saves. Make it a reflex.
  2. Ctrl + Z undoes, and Ctrl + Y redoes or repeats.
  3. Ctrl + B, Ctrl + I, Ctrl + U give bold, italic and underline.
  4. Ctrl + Shift + C and Ctrl + Shift + V copy and paste formatting from one piece of text to another.
  5. Ctrl + Space strips character formatting from the selection, back to the style's own look.
  6. Ctrl + Enter starts a new page properly, with a page break, in place of pressing Enter many times.
  7. Ctrl + Alt + 1, 2, 3 apply Heading 1, 2 and 3.
  8. Shift + F3 changes the case of the selected text.
  9. Ctrl + F finds, and Ctrl + H replaces.
  10. F12 opens Save As.

Use styles, and the shortcuts for them

Formatting each heading by hand, in bold and a larger size, looks the same on screen and gives Word no idea that it is a heading. Applying Heading 1, 2 and 3 with Ctrl + Alt + 1, 2 and 3 lets Word build a table of contents, lets you move whole sections in the Navigation pane, and lets you change every heading's look in one place. It is the single most useful habit in Word.

Page breaks, not empty lines

Pressing Enter until the text reaches the next page works until someone adds a sentence above, and then everything slides. Ctrl + Enter inserts a real break that always starts a new page.

Moving paragraphs without cutting

Put the cursor in a paragraph and press Alt + Shift + Up arrow or Down arrow. The whole paragraph moves past its neighbours. In a list it reorders items, and in a table it moves rows.

Repeating an action

After doing something once, such as applying a format or inserting a row, F4 or Ctrl + Y does the same again wherever the cursor now is.

Making your own

Word lets you give a shortcut to any command, style or symbol: File, Options, Customize Ribbon, then the Customize button beside "Keyboard shortcuts". A rupee sign, a favourite style or a phrase you type daily are good candidates.
