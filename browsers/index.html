Browser keyboard shortcuts: Chrome, Edge and Firefox

Chrome, Edge and Firefox share nearly all their keyboard shortcuts, so one list serves all three. Safari on the Mac follows most of the Mac column too. The first column is for Windows, Linux and Chromebooks. The second is for the Mac.

The eight to learn first

  1. Ctrl + T opens a new tab.
  2. Ctrl + W closes the tab you are on.
  3. Ctrl + Shift + T reopens the tab you just closed, with its history. It is the undo button of browsing.
  4. Ctrl + L jumps to the address bar, ready to type.
  5. Ctrl + Tab moves to the next tab.
  6. Ctrl + F finds a word on the page.
  7. Ctrl + Plus and Ctrl + Minus make the page larger or smaller. Ctrl + 0 puts it back.
  8. Ctrl + Shift + N opens a private window (Ctrl + Shift + P in Firefox).

Habits that save the most time

Type in the address bar, do not click it. Ctrl + L selects everything in the bar, so you can start typing a search or an address at once.

Recover from a slip. Closing a tab by mistake is the commonest browsing accident. Ctrl + Shift + T brings it back. Pressed again, it brings back the one before, and so on. It can also reopen a whole window closed by mistake.

Open links without losing your place. Ctrl + click opens a result in a background tab. Work down a list of search results that way, then read the tabs.

Reload properly when a page looks stale. A normal reload may reuse saved files. Ctrl + F5 fetches everything again.

Zoom is per site. The browser remembers the zoom level for each website, which is useful for a site whose text is always too small.

Where the three differ

  • Private browsing is Ctrl + Shift + N in Chrome and Edge and Ctrl + Shift + P in Firefox.
  • Downloads open with Ctrl + J in all three on Windows. On the Mac, Chrome uses Cmd + Shift + J and Firefox uses Cmd + J.
  • Firefox uses Ctrl + Shift + B for the bookmarks toolbar and Ctrl + Shift + O for the bookmarks library.
  • Edge adds a few of its own, such as Ctrl + Shift + U to read the page aloud.

Each browser lists its current shortcuts in its help pages, and extensions can add or take over combinations.
