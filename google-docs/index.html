Google Docs keyboard shortcuts

Google Docs runs in a browser, so its shortcuts are a mixture of its own and the browser's. This list has the ones that belong to Docs. The first column is for Windows and Chromebooks, the second for the Mac.

The eight to learn first

  1. Ctrl + / shows the full list of shortcuts inside Docs. It is the one to remember if you forget the rest.
  2. Alt + / searches the menus: type what you want to do, and Docs finds the command.
  3. Ctrl + Alt + 1, 2, 3 apply Heading 1, 2 and 3.
  4. Ctrl + Shift + V pastes without formatting.
  5. Ctrl + K inserts or edits a link.
  6. Ctrl + Alt + M adds a comment.
  7. Ctrl + Shift + 7 and Ctrl + Shift + 8 start a numbered or a bulleted list.
  8. Ctrl + Shift + C shows the word count.

No save shortcut is needed

Docs saves every change as you type. Pressing Ctrl + S does nothing harmful: Docs simply tells you that it saves automatically. To go back to an earlier state, open the version history.

Search the menus when you forget

Alt + / is the shortcut that replaces all the others. Press it, type "strikethrough" or "word count" or "page number", and choose from the list. It is quicker than hunting through menus and you do not need to remember the key for something you do once a month.

Headings make a document navigable

Applying Heading 1, 2 and 3 with Ctrl + Alt and a number builds an outline in the panel on the left, where a click takes you to any section. It also lets Docs make a table of contents. Formatting a heading by hand, in bold and large type, gives neither.

Pasting from the web

Text copied from a web page brings its fonts, colours and sizes with it. Ctrl + Shift + V pastes the words alone, in the style of the place where you paste them. For most pasting, it is the better default.

When a shortcut does nothing

Docs lives inside the browser, and the browser or an extension may be using the same keys. Some combinations also differ between browsers. If a shortcut on this page does not work, check the list inside Docs with Ctrl + /, which shows the keys for your own system.
